**ForStatement → FOR ID = Expression TO Expression DO Statement**

Navedeni identifikator je brojač for petlje, prvi navedeni izraz je inicijalna vrednost brojača, a drugi
izraz je konačna vrednost brojača. Prilikom svakog prolaska kroz petlju vrednost brojača se uvećava
za 1. 

---

## Medjukod

IMC<endExp>
IMC<startExp>
Load_Mem R1, Result startExp
Store R1, value.name

petlja:
  Load_Mem R2, Result endExp
  // Ako je R1 vece od R2, izadji iz petlje
  Compare_Greater R1, R2
  JumpIfNotZero R1, kraj
  
  IMC<statement>
  Load_Mem R1, value.name
  Load_Const R2, 1
  Add R1, R2
  Store R1, value.name
  Jump petlja

kraj:
  

---

## Kod

```js
public class ForStatement extends Statement {
  public Variable value;
  public Statement statement;
  public Expression startExp, endExp;
  
  public ForStatement(Variable value, Expression startExp, Expression endExp, Statement statement) {
    this.value = value;
    this.startExp = startExp;
    this.endExp = endExp;
    this.statement = statement;
  }
  
  public void translate( BufferedWriter out ) {
     String petlja = ASTNode.genLab();
     String kraj = ASTNode.genLab();
     
     endExp.translate(out);
     startExp.translate(out);
     startExp.genLoad("R1", out);
     out.write("Store R1, " + value.name + "\n");
     out.write(petlja + ":" + "\n");
     
     endExp.genLoad("R2", out);
     out.write( "Compare_Greater R1, R2" + "\n" );
     out.write( "JumpIfNotZero R1" + kraj );
     
     Add R1, R2
     Store R1, value.name
     Jump petlja
     
     statement.translate( out );
     out.write( "Load_Mem R1, " + value.name + "\n" );
     out.write( "Load_Const R2, 1" + "\n" );
     
     out.write( "Add R1, R2\n" );
     out.write( "Store R1, " + value.name + "\n" );
     out.write( "Jump" + petlja + "\n" );
     
     out.write(kraj + ":\n");
  }
}
```
